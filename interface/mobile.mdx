doXmind is fully responsive and optimized for mobile devices. Write, edit, and collaborate with AI from your phone or tablet.

## Responsive Design

The interface automatically adapts to your screen size:

- **Phones** - Single-panel view with bottom navigation
- **Tablets** - Flexible layout that can show sidebar or chat alongside the editor
- **Desktop** - Full three-panel layout

## Bottom Navigation Bar

On mobile devices, a bottom navigation bar provides quick access to:

| Button | Action |
|--------|--------|
| **Files** | Open the file sidebar |
| **Edit** | Focus on the editor (default view) |
| **AI Chat** | Open the chat panel |
| **More** | Additional options |

## Gesture Controls

Navigate doXmind with intuitive touch gestures:

## Touch-Optimized Editing

The editor is designed for touch interaction:

- **Tap** to place your cursor
- **Double-tap** to select a word
- **Long press** to open the context menu with Quick Edit options
- **Pinch** to zoom (if needed)

## Formatting on Mobile

The formatting toolbar adapts for touch:

- Larger tap targets for easy selection
- Scrollable toolbar for all formatting options
- Quick access to common actions

## Tips for Mobile Writing

<Tip>
**Use voice input** - Your device's voice-to-text feature works great with doXmind for hands-free drafting.
</Tip>

<Tip>
**External keyboard** - Connect a Bluetooth keyboard to your tablet for a laptop-like experience with full shortcut support.
</Tip>

<Tip>
**Portrait vs Landscape** - Use portrait mode for focused writing, landscape for more toolbar space and wider lines.
</Tip>

## AI Features on Mobile

All AI features work on mobile:

- **Autocomplete** - Suggestions appear as you type, tap to accept
- **Quick Edit** - Long-press selected text to access AI commands
- **Chat** - Swipe left or tap the chat icon to open the AI assistant
- **Knowledge Base** - Upload files from your device's storage

<Note>
For the best mobile experience, we recommend using the latest version of Chrome, Safari, or Firefox on your device.
</Note>
