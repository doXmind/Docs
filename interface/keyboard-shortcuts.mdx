Master these keyboard shortcuts to write faster and navigate doXmind efficiently.

## General

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Save | `Ctrl+S` | `Cmd+S` |
| Undo | `Ctrl+Z` | `Cmd+Z` |
| Redo | `Ctrl+Y` | `Cmd+Shift+Z` |
| Find | `Ctrl+F` | `Cmd+F` |
| Select All | `Ctrl+A` | `Cmd+A` |

## Text Formatting

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Bold | `Ctrl+B` | `Cmd+B` |
| Italic | `Ctrl+I` | `Cmd+I` |
| Underline | `Ctrl+U` | `Cmd+U` |
| Inline Code | `Ctrl+E` | `Cmd+E` |
| Link | `Ctrl+K` | `Cmd+K` |

## Headings

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Heading 1 | `Ctrl+Alt+1` | `Cmd+Alt+1` |
| Heading 2 | `Ctrl+Alt+2` | `Cmd+Alt+2` |
| Heading 3 | `Ctrl+Alt+3` | `Cmd+Alt+3` |
| Heading 4 | `Ctrl+Alt+4` | `Cmd+Alt+4` |
| Heading 5 | `Ctrl+Alt+5` | `Cmd+Alt+5` |
| Heading 6 | `Ctrl+Alt+6` | `Cmd+Alt+6` |

## Lists

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Bullet List | `Ctrl+Shift+8` | `Cmd+Shift+8` |
| Numbered List | `Ctrl+Shift+7` | `Cmd+Shift+7` |

## AI Features

| Action | Shortcut |
|--------|----------|
| Accept Autocomplete | `Tab` |
| Dismiss Autocomplete | Keep typing or `Escape` |

## Navigation

| Action | Shortcut |
|--------|----------|
| Scroll up | `↑` or `Page Up` |
| Scroll down | `↓` or `Page Down` |
| Go to start | `Ctrl+Home` |
| Go to end | `Ctrl+End` |

<Tip>
**Pro Tip:** Select text and right-click to access Quick Edit commands. This is the fastest way to apply AI-powered text transformations without leaving the keyboard.
</Tip>

## Quick Reference Card

Print or bookmark this page for a handy reference while you learn the shortcuts.

<Note>
On Mac, replace `Ctrl` with `Cmd` for most shortcuts. The exception is `Ctrl+Alt` for headings, which uses `Cmd+Alt` on Mac.
</Note>
