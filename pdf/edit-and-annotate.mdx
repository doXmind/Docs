title: "Edit and annotate PDFs"
description: "Navigate, annotate, edit extractable text, and export a new PDF."
---

Open a `.pdf` from a workspace or as a standalone file. doXmind keeps the original PDF unchanged while you work.

## Read and navigate

- Use page thumbnails to jump through the document.
- Switch between single-page, continuous, and two-page views.
- Zoom manually or use fit-width and fit-page controls.
- Use the page field and previous or next controls for direct navigation.

## Edit and annotate

- Choose **Select & edit**, then select an extracted text block to change its text or formatting.
- Choose **Add text**, then click a page to place a free-text box.
- Hold `Shift` and drag across a page to create a highlight region.
- Use the contextual controls for font, size, alignment, color, highlight, and opacity where available.
- Press `Delete` or `Backspace` to remove the selected editable object.

<Warning>
  doXmind does not include OCR. Scanned or image-only pages can be displayed, but their text is not editable unless the PDF already contains extractable text.
</Warning>

## Save versus export

**Save** stores text edits, free text, and highlights in the hidden `.pdf.doxmind` sidecar. It does not rewrite the source PDF.

**Export PDF** from **More actions (⋯)** creates a new PDF with the current edits applied. Choose a destination if prompted; otherwise check the Downloads folder configured in Settings.

<Tip>
  Save and wait for the header to show **Saved** before exporting. Open the newly exported copy to review the result; the original remains unchanged.
</Tip>

See [Local storage and sidecars](/workspaces/storage-and-sidecars) for backup guidance or [Troubleshooting](/reference/troubleshooting) if saved edits appear to be missing.
