---
title: "Spreadsheet Attachments and legacy recovery"
description: "Keep workbooks read-only and preserve any historical doXmind recovery evidence."
---

Spreadsheet files, including `.xlsx`, `.xlsm`, and `.csv`, are read-only **Attachments**. doXmind does not mount a workbook grid, calculate formulas, save workbook edits, export an edited workbook, or rewrite the source file.

Use **Open Externally** to work in your spreadsheet application, and **Reveal** to locate the original in Finder.

## Legacy recovery

Older doXmind releases could write workbook editor state beside a source file, for example `.Budget.xlsx.doxmind`. That data remains user evidence. Current doXmind can inspect legacy artifacts only through an explicit zero-write recovery export.

The recovery report is Markdown containing the exact legacy bytes. It is not a reconstructed workbook and never mounts the retired spreadsheet editor.

<Warning>
  Preserve the original workbook, main sidecar, every `.bak`, `.lock`, and `.corrupt-*` artifact together. Do not rename, replace, migrate, or delete any of them before exporting a recovery report.
</Warning>

See [Local storage and legacy sidecars](/workspaces/storage-and-sidecars) and [Troubleshooting](/reference/troubleshooting) for preservation guidance.
