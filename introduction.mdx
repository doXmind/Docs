doXmind is a desktop workspace for writing, reviewing, and organizing documents without moving them into a hosted web app. Open files from your Mac, edit them in a focused interface, and keep the original files in folders you control.

## Built around your files

Each document stays in a folder you control. Its portable source and, when present, its hidden sidecar together form the complete editable document. This keeps source files usable in other apps while preserving richer doXmind editor state.

## Local by design

- No account is required.
- There is no cloud sync, hosted document storage, or telemetry.
- doXmind has no built-in AI runtime.
- Your files stay where you put them unless you move or export them.

<Note>
  Update checks contact the release service. When you insert a web bookmark, your Mac directly requests the target page and its preview images. Document editing and storage remain local.
</Note>

doXmind does not provide cloud sync. If you place a workspace in iCloud Drive, Dropbox, or another synced folder, that provider can still sync the files under its own settings and privacy terms.

## Save and export are different

Markdown saves back to the `.md` file and its sidecar. For PDFs and spreadsheets, **Save** records the editable state in the sidecar; **Export** creates a new PDF or `.xlsx` file with the edits applied. The original PDF or workbook is not overwritten.

## Current availability

The public release currently supports **macOS on Apple silicon**. Windows and Linux installers are not yet available in the public release channel.
