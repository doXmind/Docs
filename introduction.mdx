doXmind is a desktop workspace for writing and organizing Markdown without moving it into a hosted web app. Open a real folder from your Mac, edit portable Pages in a focused interface, and keep the files where you put them.

## Built around your files

Each Page stays in a folder you control. One `.md` or `.markdown` file is the complete Page: its body, properties, tags, aliases, and links stay in Markdown or YAML frontmatter. Normal Page editing does not create a same-name `.doxmind` file.

## Local by design

- No account is required.
- There is no cloud sync, hosted document storage, or telemetry.
- doXmind has no built-in AI runtime.
- Your files stay where you put them unless you move or export a derived PDF.

doXmind does not provide cloud sync. If you place a workspace in iCloud Drive, Dropbox, or another synced folder, that provider can still sync the files under its own settings and privacy terms.

## Pages and Attachments are different

Saving a Page writes its Markdown source only. PDF, spreadsheet, and HTML files are read-only **Attachments**: doXmind does not mount an editor, save edit state, or rewrite their source bytes. Use **Open Externally** to work in the system application and **Reveal** to locate the file.

Older releases may have left PDF, spreadsheet, or Page sidecars beside a source file. They are legacy recovery evidence, not current editor state. Preserve the complete artifact family and use an explicit recovery export if you need to inspect it.

## Current availability

The public release currently supports **macOS on Apple silicon**. Windows and Linux installers are not yet available in the public release channel.
