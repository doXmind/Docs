doXmind is a desktop workspace for writing and organizing Markdown Pages without moving them into a hosted web app. Open a real folder from your Mac, edit portable Markdown in a focused interface, and keep the files in folders you control.

## Built around your files

The workspace folder is the source of truth. A **Page** is backed by a portable `.md` or `.markdown` file. Its hidden sidecar improves rich-editor fidelity, but the Page remains useful if the sidecar is missing.

## Local by design

- No account is required.
- There is no cloud sync, hosted document storage, or telemetry.
- doXmind has no built-in AI runtime.
- Your files stay where you put them unless you move or export them.

<Note>
  Update checks contact the release service. When you insert a web bookmark, your Mac directly requests the target page and its preview images. Document editing and storage remain local.
</Note>

doXmind does not provide cloud sync. If you place a workspace in iCloud Drive, Dropbox, or another synced folder, that provider can still sync the files under its own settings and privacy terms.

## Pages and Attachments are different

Saving a Page updates its portable Markdown source and hidden sidecar. PDF, spreadsheet, and HTML files are read-only **Attachments**: doXmind does not mount an editor, save new edit state, or rewrite the source. Use **Open Externally** to work in the system application and **Reveal** to locate the file.

Older doXmind releases could save PDF or spreadsheet edits in a hidden sidecar. Current releases preserve that evidence and may offer an explicit, unverified recovery attempt that creates a new comparison copy. Recovery is not an editing surface, and it never replaces the original Attachment.

## Current availability

The public release currently supports **macOS on Apple silicon**. Windows and Linux installers are not yet available in the public release channel.
