doXmind presents a Markdown Page as an editable Block document while keeping its source in one `.md` or `.markdown` file.

## Write and structure

The editor supports common Markdown structures including:

- Headings, paragraphs, and dividers
- Bulleted, numbered, and task lists
- Quotes, links, images, and Wiki Links
- Inline code and fenced code blocks
- Tables, math, Mermaid, callouts, and toggles

Type `/` to open the Block menu, or press `Cmd+K` to open the command palette. Unsupported syntax remains available as exact raw Markdown instead of being silently changed.

## Navigate a long Page

- Open the outline to jump between headings.
- Press `Cmd+F` to search within the current Page.
- Press `F11` for focus mode.
- Press `Cmd+B` to show or hide the workspace sidebar.

## Work with external Markdown

The `.md` file remains readable and editable outside doXmind. When another editor changes it, doXmind treats the external source as authoritative and shows a conflict prompt if the open Page has changed locally.

Page state is Markdown itself: doXmind does not maintain a same-name Page sidecar or HTML editor document. Properties, aliases, tags, and links live in YAML frontmatter or visible Markdown.
