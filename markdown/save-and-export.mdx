---
title: "Save and export Pages"
description: "Save portable Markdown and create local PDF copies."
---

## Save

Press `Cmd+S` to update the Page's `.md` or `.markdown` source. Page body, properties, aliases, tags, links, and supported Block syntax are written to canonical Markdown and YAML frontmatter.

The source file is the complete Page. A normal save does not create or update a same-name `.doxmind` sidecar.

## Export PDF

Use **Export PDF** to create a PDF copy of the rendered Page. Choose a destination in the macOS save dialog; the original Markdown Page remains unchanged.

<Note>
  PDF export is derived output. It does not turn the PDF into an editable Page or Attachment state.
</Note>

## External edits

If the Markdown file changes outside doXmind, the external text remains authoritative. Resolve the visible conflict before continuing with local edits.
