title: "Rich blocks"
description: "Use doXmind's extended Markdown blocks for structured Pages."
---

Open the block menu with `/` to insert content beyond basic paragraphs and lists.

## Available blocks

### Callouts and toggles

Use callouts to emphasize notes, tips, warnings, and important context. Toggles keep supporting detail collapsed until a reader needs it.

### Math

Add inline and display math using KaTeX syntax. Math remains represented in the Markdown source.

### Mermaid diagrams

Insert a Mermaid block to render flowcharts and other diagrams from text. The source is stored in a fenced Mermaid code block, so it remains portable.

### Code blocks

Add fenced code blocks with a language for syntax highlighting.

### Images and web bookmarks

Images can reference local workspace assets. Web bookmarks create a visual link preview; fetching that preview requires an internet connection.

### Columns and table of contents

Columns support side-by-side layouts. A table-of-contents block follows the headings in the current Page.

### Page links

Link to another Markdown Page in the same workspace to connect related notes and plans.

<Note>
  Rich layout and editor-only details are stored in the hidden `.doxmind` sidecar. Keep that sidecar with the Markdown file to preserve the complete editing experience.
</Note>
