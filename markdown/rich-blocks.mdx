title: "Rich blocks"

---

Open the Block menu with `/` to insert common Markdown structures. Each supported Block writes visible source rather than a hidden editor record.

## Available Blocks

### Callouts and toggles

Use callouts to emphasize notes, tips, warnings, and important context. Toggles use portable `<details>` and `<summary>` source with Markdown content.

### Math and diagrams

Add inline or display math with KaTeX syntax. Mermaid diagrams are stored in fenced `mermaid` code blocks, so their source remains portable.

### Code and tables

Use fenced code blocks with an optional language. Tables preserve the Markdown delimiter row, including column alignment.

### Images and links

Images use relative Markdown references to workspace assets. Link Pages with `[[Wiki Links]]`, standard Markdown links, or visible `^block-id` anchors for unique block embeds.

### Raw Markdown

Some syntax is not rendered as a dedicated Block yet, including footnotes, reference-style links, definition lists, and some inline math. It stays editable as exact raw Markdown.

<Note>
  A Page's complete editable state is its Markdown source. There is no current rich-layout sidecar to keep beside the file.
</Note>
