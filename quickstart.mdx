## 1. Install the desktop app

<Steps>
  <Step title="Download the latest release">
    Download the [macOS Apple silicon `.dmg`](https://github.com/doXmind/releases/releases/latest/download/doXmind-mac-arm64.dmg).
  </Step>
  <Step title="Move doXmind to Applications">
    Open the disk image, then drag doXmind into your Applications folder.
  </Step>
  <Step title="Launch doXmind">
    Open doXmind from Applications. No account or sign-in is required.
  </Step>
</Steps>

## 2. Choose how to start

The welcome screen gives you two primary actions, and the File menu provides standalone opening:

- **New** — create an untitled Page and choose its Markdown filename on first save.
- **Open Folder** — use a real folder as a workspace and browse supported Pages, Attachments, and subfolders in the sidebar.
- **File → Open File…** (`Cmd+O`) — open one Markdown Page or supported Attachment without creating a workspace. You can also drag a supported file onto the welcome screen or open it with doXmind from Finder.

For ongoing projects, choose **Open Folder**. doXmind only works inside the folder you select and its subfolders.

## 3. Create or open a Page

In a folder workspace, the **+** menu creates a blank Page, a folder, or a Page from a template. It does not create blank PDFs or workbooks. Existing `.pdf`, `.xlsx`, `.xlsm`, `.csv`, `.html`, and `.htm` files can appear as read-only Attachments.

## 4. Save your work

Press `Cmd+S` to save the current Page immediately. Autosave also writes after a short pause.

- The portable Markdown is written to the `.md` or `.markdown` source.
- Lossless editor HTML and replaceable UI state are written to a same-name hidden `.doxmind` sidecar.
- **Export Markdown** and **Export PDF** create copies of the current Page.

<Warning>
  Attachments are not editable in doXmind. If an older release created a PDF or spreadsheet sidecar, preserve the source, sidecar, `.bak`, `.lock`, and `.corrupt-*` files together until recovery is independently verified.
</Warning>
