## 1. Install the desktop app

<Steps>
  <Step title="Download the latest release">
    Download the [macOS Apple silicon `.dmg`](https://github.com/doXmind/releases/releases/latest/download/doXmind-mac-arm64.dmg).
  </Step>
  <Step title="Move doXmind to Applications">
    Open the disk image, then drag doXmind into your Applications folder.
  </Step>
  <Step title="Launch doXmind">
    Open doXmind from Applications. No account or sign-in is required.
  </Step>
</Steps>

## 2. Choose how to start

The welcome screen lets you open a folder workspace or a single file. For ongoing projects, choose **Open Folder**: doXmind works only inside the folder you select and its subfolders.

- **Open Folder** — browse Pages, supported Attachments, and subfolders in the sidebar.
- **Open File** — open one Markdown Page or supported Attachment without creating a workspace.
- **New Page** — create a new local Markdown file.

## 3. Create or open a Page

In a folder workspace, the **New** menu creates a Page, a folder, or a Page from a template. It does not create PDFs or workbooks. Existing `.md`, `.markdown`, `.pdf`, spreadsheet, and HTML files can appear in the workspace.

## 4. Save your work

Press `Cmd+S` to save the current Page to its `.md` or `.markdown` source. Use **Export PDF** on a Page to create a derived PDF at a destination you choose.

PDF, spreadsheet, and HTML files are read-only Attachments. Use **Open Externally** or **Reveal** for the original file.

<Warning>
  An existing `.doxmind`, `.bak`, `.lock`, or `.corrupt-*` artifact is legacy recovery evidence. Keep it with its source file; current doXmind never overwrites or deletes it.
</Warning>
