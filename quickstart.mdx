## 1. Install the desktop app

<Steps>
  <Step title="Download the latest release">
    Download the [macOS Apple silicon `.dmg`](https://github.com/doXmind/releases/releases/latest/download/doXmind-mac-arm64.dmg).
  </Step>
  <Step title="Move doXmind to Applications">
    Open the disk image, then drag doXmind into your Applications folder.
  </Step>
  <Step title="Launch doXmind">
    Open doXmind from Applications. No account or sign-in is required.
  </Step>
</Steps>

## 2. Choose how to start

The welcome screen gives you three options:

- **Open Folder** — use a folder as a workspace and browse its documents in the sidebar.
- **Open File** — open one Markdown, PDF, or Excel file without creating a workspace.
- **New Document** — create a new local Markdown file.

For ongoing projects, choose **Open Folder**. doXmind only works inside the folder you select and its subfolders.

## 3. Create or open a document

In a folder workspace, use the sidebar to create a blank Markdown document, a PDF, a spreadsheet, or a new folder. You can also open existing `.md`, `.markdown`, `.pdf`, and `.xlsx` files.

## 4. Save your work

Press `Cmd+S`.

- Markdown saves to the source file and a hidden sidecar.
- PDF and spreadsheet edits save to a hidden sidecar next to the original.
- To create a new edited PDF or workbook, choose **Export PDF** or **Export XLSX** from the document menu.

<Warning>
  Keep each hidden `.doxmind` sidecar with its source file when moving, copying, restoring, or backing up a document. PDF and spreadsheet edits live in that sidecar until you export a new file.
</Warning>
