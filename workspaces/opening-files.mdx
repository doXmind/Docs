---
title: "Open files and folders"
description: "Choose a folder workspace, open a standalone Page or Attachment, or create a new Markdown Page."
---

doXmind works directly with files on your Mac. You can open a folder for an ongoing project or open one supported file for a focused task.

## Open a folder workspace

Choose **Open Folder** on the welcome screen, or press `Cmd+Shift+O`.

A folder workspace gives you:

- A sidebar for Markdown Pages, supported Attachments, and subfolders
- Tools to create and organize Pages and folders
- Quick switching between open files
- Portable links between Markdown Pages

doXmind works within the folder you select and its subfolders. If you need access to a different project, open that folder as a new workspace.

## Open one file

Choose **File → Open File…**, or press `Cmd+O`, to open a standalone Markdown Page or supported Attachment. You can also drag a supported file onto the welcome screen or open it with doXmind from Finder. A normal Attachment opens read-only and does not receive a new sidecar. If legacy recovery evidence already exists, doXmind inspects it without rewriting it.

## Create a new Page

Press `Cmd+N` to create a Page. In a folder workspace, the sidebar **+** menu can create:

- Blank Markdown Pages
- Pages from a template
- Folders

doXmind does not create blank PDFs or workbooks.

## Switch between files

Press `Cmd+P` from the native Edit menu to open the quick file switcher. The app also assigns `Cmd+Tab`; macOS may use that combination for application switching. You can always select a file from the sidebar or recent files list.

<Tip>
  Use `Cmd+Option+R` to reveal the current source file in Finder.
</Tip>

## Supported workspace files

`.md` and `.markdown` are editable Pages. PDF, spreadsheet (`.xlsx`, `.xlsm`, `.csv`), and HTML (`.html`, `.htm`) files are read-only Attachments. Standalone images, DOCX, PPTX, and arbitrary other extensions are not promised as workspace documents. See [Supported formats](/reference/supported-formats) for details.
