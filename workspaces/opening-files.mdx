title: "Open files and folders"
description: "Choose a folder workspace, open a standalone file, or create a new document."
---

doXmind works directly with documents on your Mac. You can open a folder for an ongoing project or open one file for a focused task.

## Open a folder workspace

Choose **Open Folder** on the welcome screen, or press `Cmd+Shift+O`.

A folder workspace gives you:

- A sidebar for supported files and subfolders
- Tools to create, rename, move, and delete documents
- Quick switching between open documents
- Local page links between Markdown documents

doXmind works within the folder you select and its subfolders. If you need access to a different project, open that folder as a new workspace.

## Open one file

Choose **Open File**, or press `Cmd+O`, to work on a standalone Markdown, PDF, or supported workbook file. doXmind creates any required sidecar next to that file.

## Create a new document

Press `Cmd+N` to create a Markdown document. In a folder workspace, the sidebar can also create:

- Blank Markdown documents
- Markdown documents from a template
- Blank PDFs
- Blank Excel workbooks
- Folders

## Switch between documents

Press `Cmd+P` from the native Edit menu to open the quick file switcher. The app also assigns `Cmd+Tab`; macOS may use that combination for application switching. You can always select a file from the sidebar or recent documents list.

<Tip>
  Use `Cmd+Option+R` to reveal the current source file in Finder.
</Tip>

## Supported files

The stable editing formats are `.md`, `.markdown`, `.pdf`, and `.xlsx`. Macro-enabled `.xlsm` files have limited support. See [Supported formats](/reference/supported-formats) for details.
