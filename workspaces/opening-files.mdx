---
title: "Open files and folders"
description: "Choose a folder workspace, open a standalone Page or Attachment, or create a new Page."
---

doXmind works directly with files on your Mac. Open a folder for an ongoing project or open one file for a focused task.

## Open a folder workspace

Choose **Open Folder** on the welcome screen, or press `Cmd+Shift+O`.

A folder workspace gives you:

- A sidebar for Markdown Pages, supported Attachments, and subfolders
- Tools to create, rename, move, and delete Pages and folders
- Quick switching between open Pages
- Local links between Markdown Pages

doXmind works within the folder you select and its subfolders. If you need access to a different project, open that folder as a new workspace.

## Open one file

Choose **Open File**, or press `Cmd+O`, to open a standalone Markdown Page or supported Attachment. A Page remains its original Markdown file; opening an Attachment does not create a sidecar or rewrite it.

## Create a new Page

Press `Cmd+N` to create a Markdown Page. In a folder workspace, the sidebar can also create:

- Blank Markdown Pages
- Markdown Pages from a template
- Folders

## Switch between Pages

Press `Cmd+P` from the native Edit menu to open the quick file switcher. You can always select a file from the sidebar or recent Pages list.

<Tip>
  Use `Cmd+Option+R` to reveal the current source file in Finder.
</Tip>

## Supported files

`.md` and `.markdown` are editable Pages. PDF, spreadsheet (`.xlsx`, `.xlsm`, `.csv`), and HTML (`.html`, `.htm`) files are read-only Attachments. See [Supported formats](/reference/supported-formats) for details.
