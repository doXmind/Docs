---
title: "Local storage and legacy sidecars"
description: "Understand portable Markdown Pages and preserve legacy recovery artifacts."
---

Your source files stay in the folders you choose. A Markdown Page is one complete `.md` or `.markdown` file. Its body, properties, aliases, tags, and links are stored in Markdown or YAML frontmatter; normal Page work does not create a same-name `.doxmind` file.

```text
Project/
├── Project Plan.md
├── Research Report.pdf
├── Quarterly Plan.xlsx
└── assets/
    └── diagram.png
```

## What doXmind writes

| Item | Source of truth | Current write behavior |
| --- | --- | --- |
| Markdown Page | One `.md` or `.markdown` file | Updates only the Markdown source |
| Ordinary Attachment | The original PDF, spreadsheet, or HTML file | Never rewritten by doXmind |
| Legacy sidecar | Historical evidence beside a source file | Read only through explicit recovery export |

## Legacy sidecars

Older versions could create hidden `.doxmind` sidecars beside Pages, PDFs, or spreadsheets. Those bytes can contain user work, but they are not part of the current Page or Attachment model. Keep the complete artifact family together when it exists.

<Warning>
  Do not manually edit, replace, or delete a legacy `.doxmind` sidecar. Current recovery exports a Markdown report with exact legacy bytes; it never recreates the retired editor or rewrites the source file.
</Warning>

- A `<sidecar>.lock` file may remain after an older operation; do not delete it manually.
- A `<sidecar>.bak` file is a historical backup.
- A `<sidecar>.corrupt-*` file preserves unreadable evidence.

For an everyday backup, preserve the full workspace folder, including hidden files. If legacy artifacts exist, preserve them with their source and export a recovery report before considering any cleanup.

## Privacy and network access

doXmind does not upload documents, provide cloud sync, or require an account. Folders stored in iCloud Drive, Dropbox, or another synced location can still be uploaded by that provider according to its settings.
