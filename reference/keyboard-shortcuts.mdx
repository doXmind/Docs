---
title: "Keyboard shortcuts"
description: "Navigate and edit faster in the macOS desktop app."
---

The current public release uses macOS shortcuts.

| Action | Shortcut |
| --- | --- |
| New Page in an open workspace | `Cmd+N` |
| New window | `Cmd+Shift+N` |
| Open file | `Cmd+O` |
| Open folder | `Cmd+Shift+O` |
| Save | `Cmd+S` |
| Find in document or workbook | `Cmd+F` |
| Command palette | `Cmd+K` |
| Quick file switcher | `Cmd+Tab` |
| Quick file switcher from the Edit menu | `Cmd+P` |
| Toggle sidebar | `Cmd+B` |
| Focus mode | `F11` |
| Exit focus mode | `Esc` |
| Shortcut reference | `Cmd+Shift+?` |
| Reveal active source file in Finder | `Cmd+Option+R` |

Standard shortcuts for undo, redo, cut, copy, paste, and select all work in the active editor.

<Tip>
  Press `Cmd+Shift+?` inside doXmind for the shortcut reference available in your installed version.
</Tip>
