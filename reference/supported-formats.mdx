## Pages

| Format | Open | Edit | Save behavior |
| --- | --- | --- | --- |
| `.md`, `.markdown` | Yes | Yes | Updates the portable Markdown source |

Markdown Pages are the only first-class editable content type. One Markdown file is complete and remains useful in other Markdown tools.

## Attachments

| Format | Current behavior |
| --- | --- |
| `.pdf` | Read-only Attachment; Open Externally, Reveal, and eligible legacy recovery export |
| `.xlsx`, `.xlsm`, `.csv` | Read-only Attachment; Open Externally, Reveal, and eligible legacy recovery export |
| `.html`, `.htm` | Read-only Attachment; Open Externally and Reveal |

Opening an ordinary Attachment does not create a sidecar or rewrite the source. doXmind does not provide PDF annotation, workbook formulas or formatting, or HTML editing.

## Other files

Images can be referenced from a Markdown Page as local assets. DOCX, PPTX, standalone images, and arbitrary other extensions are not promised as workspace documents.

The internal `other` Attachment type is only a safe read-only fallback if an unknown format reaches the shared surface. It is not a promise that doXmind scans, lists, or registers every file type.

## Legacy artifacts

Older doXmind releases could create editable state beside PDF and spreadsheet files. Current releases preserve those sidecars only as recovery evidence. They do not resume the old editor or write new Attachment edit state.

Recovery is explicit and zero-write: it exports a Markdown report containing exact legacy bytes while leaving the source and its artifacts unchanged. See [PDF Attachments and legacy recovery](/pdf/edit-and-annotate) and [Spreadsheet Attachments and legacy recovery](/spreadsheets/workbooks).
