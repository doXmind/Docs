## Pages

| Format | Open | Edit | Save behavior |
| --- | --- | --- | --- |
| `.md`, `.markdown` | Yes | Yes | Updates the portable Markdown source and same-name hidden sidecar |

Markdown Pages are the only first-class editable content type. A Page remains readable in other Markdown tools even if its `.doxmind` sidecar is missing.

## Attachments

| Format | Workspace behavior | Available actions |
| --- | --- | --- |
| `.pdf` | Read-only Attachment | Open Externally, Reveal, and eligible legacy recovery |
| `.xlsx`, `.xlsm`, `.csv` | Read-only Attachment | Open Externally, Reveal, and eligible legacy recovery |
| `.html`, `.htm` | Read-only Attachment | Open Externally and Reveal |

Opening an ordinary Attachment does not create a sidecar or rewrite the source. doXmind does not provide PDF annotation, workbook formulas, formatting, or HTML editing in the current product.

Attachments do not currently have an embedded document preview. Use **Open Externally** for ordinary reading or editing in the file's system application.

## Local Page assets

Images inserted into a Page remain ordinary local assets referenced by Markdown. Standalone images are not promised as separate workspace documents.

## Not currently supported as workspace documents

- `.docx` and `.pptx`
- Standalone image files
- Arbitrary extensions outside the supported Page and Attachment list

The internal `other` Attachment type is only a safe read-only fallback if an unknown format reaches the shared surface. It is not a promise that doXmind scans, lists, or registers every file type.

## Legacy compatibility

Older doXmind releases could create editable state beside PDF and spreadsheet files. Current releases preserve those sidecars only for recovery. They do not resume the old editor or write new Attachment edit state.

Recovery is explicit, all-or-nothing, and unverified. It creates a new comparison copy when supported state can be applied safely, while leaving the source and every recovery artifact unchanged. See [PDF Attachments and legacy recovery](/attachments/pdf) and [Spreadsheet Attachments and legacy recovery](/attachments/spreadsheets).
