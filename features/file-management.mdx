doXmind makes it easy to manage your documents. Import existing files, organize them in the sidebar, and export your work when you're done.

## Creating Documents

Click the **+** button in the sidebar to create a new document. Give it a name and start writing immediately.

Your documents are saved automatically as you type - no need to manually save.

## Importing Files

Import existing documents to edit them in doXmind. Files are converted to Markdown format for editing.

### Supported Import Formats

<CardGroup cols={3}>
  <Card title="PDF" icon="file-pdf">
    Text is extracted and converted to editable Markdown.
  </Card>
  <Card title="Word (.docx)" icon="file-word">
    Formatting is preserved where possible during conversion.
  </Card>
  <Card title="Markdown (.md)" icon="file-code">
    Direct import with no conversion needed.
  </Card>
</CardGroup>

### How to Import

<Steps>
  <Step title="Open import">
    Click the import button in the sidebar, or drag a file directly into the application.
  </Step>
  <Step title="Select your file">
    Choose the PDF, Word, or Markdown file you want to import.
  </Step>
  <Step title="Review and edit">
    The file is converted to Markdown and opens in the editor. Review the conversion and make any needed adjustments.
  </Step>
</Steps>

<Note>
Complex PDF layouts (multiple columns, embedded images, tables) may require some manual cleanup after import. The AI can help you fix formatting issues.
</Note>

## File Sidebar

The left sidebar shows all your documents:

- **Click** a file to open it
- **Right-click** for options (rename, delete)
- **Search** to find files by name or content

## Exporting Documents

Export your finished work to share or use elsewhere:

1. Open the file you want to export
2. Click the export button in the toolbar
3. Choose your format

### Export Formats

- **Markdown (.md)** - Plain text with Markdown formatting
- **PDF** - Formatted document ready for sharing or printing
- **Word (.docx)** - Microsoft Word format for further editing

<Tip>
Use the AI to help prepare your document for export. Ask it to review formatting, check for consistency, or add finishing touches before you export.
</Tip>
